# 玉米点云处理的完整技术路线

按主要处理环节，说明每一步用什么方法、做什么、得到什么。当前默认流程如下：

```text
带标签的原始点云
  ↓
欧氏聚类：去掉零散小块
  ↓
MAD-SOR：去掉局部毛刺
  ↓
拟合茎秆中心线 → 提取叶片中脉 → 确定叶面方向
  ↓
拟合叶宽和表面起伏，比较多个建模方案
  ↓
按扫描范围收紧边界，检查并保存三维模型
  ↓
计算叶长、面积、角度等指标
  ↓
根据四个指标分成紧缩、舒展、下垂
  ↓
网页查看整株、单叶和分类结果
```

## 1、读取原始点云

**第一步：配对文件。** 从 `dataset/` 读取同名 `.txt` 和 `.csv`，两份文件中的点需要逐行对应。

**第二步：读取标签。** `.csv` 中的 `semantic = 0` 表示茎，正整数表示不同叶片。

**第三步：分开处理。** 取出茎秆点，再按叶片编号逐片重建。茎和叶的标签需要提前准备好。

**得到：** 茎秆点云、每片叶的点云，以及颜色和可选的扫描法向。法向表示叶面朝向。

## 2、去噪第一步：欧氏聚类（Euclidean Clustering）

作用：**把距离近的点连成块，去掉零散小块，同时保留有一定规模的断片。** 以下计算在每片叶内部进行。

**第一步：删除重复点。** 完全相同的坐标只保留一次。

**第二步：计算典型点间距 s。** 用 KD-tree 快速查找每个点最近的其他点，取这些距离的中位数。

**第三步：计算整体尺寸 D。** 分别求 X、Y、Z 坐标的 1% 和 99% 分位值，计算这个范围的包围盒对角线长度，减少远处飞点的影响。

**第四步：计算连接半径 r。**

```text
r = max(5 × s, 0.02 × D)
```

两点距离不超过 `r`，就建立连接。直接或间接连在一起的点组成一个连通块。

**第五步：筛选连通块。** 最大的一块始终保留；其他块达到下面的点数门槛也保留：

```text
最小点数 = max(20, 向下取整(去重后点数 × 1%))
```

**得到：** 去掉小型离散块后的叶片点云，并记录每个保留块的编号。

## 3、去噪第二步：MAD-SOR 统计离群点去除

作用：**在每个保留块内部，找出离周围点明显偏远的毛刺。** 各块分别计算，避免把稀疏叶尖直接拿来与密集叶身比较。

- **SOR**：统计离群点去除。
- **MAD**：中位数绝对偏差，用来表示一组数有多分散。

**第一步：计算局部平均距离 d。** 对每个点找到最近的 `K = 8` 个其他点，计算距离的平均值。

**第二步：计算距离分布。** 在当前块内，求所有 `d` 的中位数 `m`，再计算每个 `d` 偏离 `m` 的程度。

**第三步：计算删除阈值。**

```text
MAD = 所有 |d − m| 的中位数
稳健标准差 = 1.4826 × MAD
阈值 T = m + 3.5 × 稳健标准差
```

`d ≤ T` 的点保留，`d > T` 的点删除。若 MAD 为零，则改用普通标准差。

**第四步：检查是否删得过多。** 如果剩余点数少于 `max(15, 向下取整(该块点数 × 75%))`，撤销该块这次删除；不足 20 点的块跳过此步骤。

**得到：** 用于后续建模的去噪叶片点云。`K = 8` 和系数 `3.5` 是当前默认值。

## 4、拟合茎秆中心线

作用：**确定茎在哪里、朝哪个方向生长，为判断叶基和计算茎叶角提供参照。**

这条中心线由茎秆点单独拟合，在每片叶建模前准备好。

**第一步：按高度分层。** 将茎秆点沿 Z 轴分成若干层。

**第二步：取每层的中间位置。** 用各层坐标的中位数代表该层中心。

**第三步：连接成光滑曲线。** 使用带平滑约束的 B 样条（P-spline）拟合，自动选择平滑程度。

**得到：** 茎秆中心线，以及沿茎秆变化的局部方向。

## 5、提取每片叶的中脉

作用：**找到从叶基到叶尖的中心走向。**

**第一步：提取细骨架。** 用 L1 中位收缩方法，将叶片点云逐步集中成细长骨架。

**第二步：确定起点和顺序。** 以靠近茎秆的一端作为叶基，沿骨架上的路径向叶尖排序；骨架存在断口时连接相邻断片。

**第三步：拟合光滑中脉。** 根据骨架点拟合曲线，并用原始保留点继续调整。

**第四步：检查是否覆盖整片叶。** 若骨架漏掉较长的末端，或曲线明显折返，则改用沿叶片主方向分层取中位点的方案。

**得到：** 中脉曲线、观测长度，以及各点沿中脉的位置。

## 6、建立叶片的局部坐标系

作用：**在弯曲的叶片上，分清“沿叶长”“向左右”“离开叶面”三个方向。**

**第一步：沿中脉建立三个方向。** 用双反射方法生成连续变化的坐标系，减少沿途突然翻转。

**第二步：对齐实际叶面。** 有扫描法向时，根据法向调整朝向；没有法向时，根据附近点的分布估计。

**第三步：转换点坐标。** 把三维点表示成沿叶长的位置、左右偏移和上下起伏。

**得到：** 便于计算叶宽和拟合表面的局部坐标。

## 7、拟合叶宽和叶面，选择建模方案

作用：**把中脉周围的点连成一张光滑的三维叶面。**

**第一步：统计叶宽。** 沿叶长分成 32 段，根据每段点的左右分布提取边缘和宽度。

**第二步：拟合宽度变化。** 用 Dornbusch 叶形函数描述叶片从基部到末端的宽度变化，再结合实测边缘修正宽度。程序也会从符合条件的完整叶尖样本中估计共享叶形参数。

**第三步：拟合上下起伏。** 将局部点分箱取中位代表点，用薄板样条（TPS）拟合光滑表面，自动选择平滑程度。

**第四步：比较 5 个方案。** 分别使用联合优化中脉、初始中脉、平滑中脉、主轴平滑中脉和直线参考，比较贴合距离、反向支撑距离和质量检查结果。反向支撑距离用于检查叶面是否离扫描点太远。

**第五步：必要时加密拟合。** 初始 TPS 代表点上限为 `350`；贴合或质量未达要求时，尝试增加到 `700`，再按代码中的验收条件决定是否采用。

**得到：** 选出的三维叶面模型。所有候选均不通过最终质量检查时，程序报错。

## 8、按扫描范围收紧叶片边界

作用：**让最终叶面沿着实际扫描范围展开。** 此步骤在候选模型构建时执行，单列出来便于理解。

**第一步：分别确定左右边缘。** 根据各段扫描点的左右边界限制模型，两侧独立处理。

**第二步：保留少量边缘余量。** 默认余量为 `2.5 × 典型点间距`，再将边界平滑连接。

**第三步：限制叶尖范围。** 默认撤下超过观测长度的延长段。扫描叶尖被截断时，模型保留开放截面。

**得到：** 最终参与网格导出、表型测量和可视化的同一片叶面。叶片内部的小缺口仍可能包含插值估计。

## 9、生成网格、标记区域并检查质量

**第一步：生成三角网格。** 在光滑叶面上采样并连接成小三角形。

**第二步：标记区域。** 靠近真实扫描点的是观测区；扫描轮廓内部缺点、由周围补出的部分是插值区；超出扫描点凸包范围的是外推区。

**第三步：检查质量。** 检查网格连接、退化面、表面方向、连续性和点云贴合误差，同时记录远离点云的面积占比。

**第四步：保存结果。** 将连续模型保存为 `.npz`，网格保存为 `.ply`、`.obj`，质量和参数保存为 `.json`。

**得到：** `outputs/maize_v2/` 下的单叶模型、整株网格和质量记录。

## 10、提取叶片和整株表型

作用：**把模型变成可以比较、统计的数值。** 表型在这里就是可测量的形状和姿态指标。

**第一步：量基本尺寸。** 沿叶面中心线量长度，计算最大宽度，并累加小三角形面积。

**第二步：计算分类用的 4 个指标。**

| 指标 | 计算方法 |
|---|---|
| 茎叶角 θ | 叶基前 15% 叶面的平均纵向方向，与叶基附近茎秆向上方向的夹角 |
| 相对投影面积 P | 各小面片水平投影面积之和，除以同株最大值；重叠部分重复计入 |
| 俯仰熵 H | 将叶面沿叶长方向的俯仰角分成 12 档，按面积计算方向分散程度，归一化到 0～1 |
| 相对着生高度 h | `(叶基高度 − 扫描茎底高度) ÷ 扫描茎的高度跨度`，限制在 0～1 |

**第三步：计算其他指标。** 包括叶片弯曲程度、各区域面积占比，以及整株的总叶面积、投影和遮挡情况。

**得到：** `outputs/phenotypes_v2/` 中的逐叶、逐株指标表和参数记录。长度和面积沿用输入坐标单位及其平方。

## 11、将叶片分成紧缩、舒展、下垂

**第一步：取出 4 个指标。** 使用 `[θ, P, H, h]`。

**第二步：统一数值尺度。** 每项减去中位数，再除以四分位距，也就是中间一半数据的跨度。

**第三步：学习 3 个典型形态。** 使用 K-means++，设 `k = 3`、初始化 `50` 次、随机种子 `42`。比较平方距离时，四项权重依次为 `[1, 1, 1, 0.5]`。按中心的茎叶角从小到大，将它们称为紧缩、舒展、下垂中心。

**第四步：应用类别规则。** 距离越小，说明综合形态越接近该中心。

- **紧缩：** 最近的是紧缩中心，到它的距离不超过第二近中心的 `2/3`，同时 `P ≤ 0.5`，且与同株最高叶的相对着生高度差不超过 `0.15`。
- **下垂：** 最近的是下垂中心，且到它的距离不超过到舒展中心距离的 `2/3`。
- **舒展：** 其余叶片，包括过渡形态。

**第五步：检查稳定性。** 每次留出一株，用其余植株重新学习，再预测留出植株；同时比较不同特征和权重设置下的结果。这些检查用于评价分类稳定性，准确率需要另有人工标签才能评价。

**得到：** `outputs/classification_v2/` 中的逐叶分类表、逐株类别统计和验证报告。每株可以缺少某类，不设类别数量配额；上述阈值是当前开发设置。

## 12、三维可视化与人工核对

**第一步：加载结果。** 网页读取三维模型和分类表。

**第二步：查看整株。** 旋转、缩放，按紧缩、舒展、下垂着色或筛选。

**第三步：查看单叶。** 点击叶片查看 4 个指标，按需勾选“仅看选中叶”。

**第四步：检查估计区域。** 默认显示观测区；勾选“显示插值/外推面”查看补出的区域，结合点云检查贴合情况。

**得到：** 可交互查看的页面，也可导出离线 HTML。页面操作用于查看，不会修改已保存的模型和数值。

## 对应的运行命令

在项目根目录依次运行。第一个脚本包含上面的第 1～9 环节。

```bash
python scripts/run.py                    # 点云去噪、三维重建和质量检查
python scripts/extract_traits.py         # 表型提取
python scripts/classify_leaf_pose.py     # 叶姿分类和稳定性检查
python scripts/visualize.py              # 网页查看
```

已有模型和分类结果时，直接运行最后一条即可。新实验给各阶段指定新的输入、输出目录，避免覆盖旧结果，参数见[脚本说明](../scripts/README.md)。

更简短的介绍见[方法说明](method.md)。实现主要位于 [`geometry.py`](../src/maize_leaf/geometry.py)、[`surface.py`](../src/maize_leaf/surface.py)、[`traits.py`](../src/maize_leaf/traits.py)、[`classification.py`](../src/maize_leaf/classification.py)。
