# V1.1 玉米叶片表型计算口径

## 输入和叶基

每株配对同名 TXT 和语义 CSV，沿用 V1.0 的逐行 XYZ 与语义核验。−1 为背景，0 为茎秆，全部正整数各自表示一片叶。p 为 V1.0 最近叶点，q 为与其成对的最近茎点。输出保留两个原始点及零基点数据行号。每株的输入哈希、实际点数和失败详情见 input_manifest.csv。

茎线沿用仓库的稳健核心截面和惩罚 B 样条拟合。茎主轴单位向量 a 朝向输入 +Z。叶片体素近邻图的主连通分量按原始点数确定，从 p 附近启动测地搜索。用图上两个端部区域距 p 的距离选择根端，按双端测地坐标划分截面，拟合可见中线。固定运行默认配置 k=10、连接间隔上限 6 倍图间距，以及 k=8 / 4 倍和 k=12 / 8 倍两种扰动。端点分别由可见中线拟合得到。原始叶基点 p 不参与修改或外推中线。

## 数学定义

令 S(s) 为沿茎线弧长参数化的曲线，总弧长 Lₛ。令 C(u) 为叶片可见中线，弧长 sᵢ，长度 L。C₀、C₁ 分别为可见近端和远端。绝对弧长和位移沿用原始坐标单位。

| 特征 | 定义 |
|---|---|
| 归一化着生高度 | 将 q 正交投影到茎线折线，取最短投影处的累计弧长 ŝ。高度比 h=ŝ/Lₛ |
| 叶茎夹角 | θ=arccos(tₛ·tₗ)×180/π。tₛ 是 ŝ 处指向茎顶的单位切向，tₗ 是叶中线起始 12% 弧长内的有向 PCA 主轴，窗口不足四个采样顶点时取前四点 |
| 下垂指数 | max(0, −minᵤ[(C(u)−C₀)·a])/L。分子是可见近端以下的最大轴向落差 |
| 归一化 RMS 曲率 | √(L∫₀ᴸ κ(s)² ds)，κ=‖C′×C″‖/‖C′‖³。对 240 个样条采样位置按弧长用梯形积分 |
| 水平延展指数 | ‖d−(d·a)a‖/L，d=C₁−C₀。对应相对茎轴的横向端点净位移 |
| 倾角 Shannon 熵 | 对相邻中线点组成的非零弧段 ΔCᵢ，计算 αᵢ=arccos((ΔCᵢ·a)/‖ΔCᵢ‖)×180/π。以边界 0°、10°、…、180° 分箱，pⱼ 为箱内弧段长度之和除以总长。H=−Σⱼ pⱼlog₂pⱼ，零概率项略过，单位 bit |

熵衡量可见中线长度在倾角箱中的分散程度。均匀使用 18 箱时为 log₂18 bit，单箱时为 0。箱边界固定，包含 180° 的上边界。每片叶的箱概率单独保存于 quality_details.json。

## 质量与缺失

- 着生高度要求茎线投影有邻近有效截面支撑、投影位于拟合区间内部，且最近点对间距不超过 max(3×茎核心半径，4×较大的叶或茎原始中位最近邻间距)。
- 中线特征要求至少 200 个有效叶点、主连通分量保留至少 94% 叶点、至少 90% 中线采样点处有 3.5 倍图间距内的观测支持，以及 16 个等弧长箱中至少 85% 含三个点。p 到拟合近端距离需在 max(0.12L，4×图间距) 内，两个端区对 p 的距离差须大于 2 倍图间距。
- 默认中线和至少一个邻域扰动需同时通过上述规则，有效变体长度的极差除以主中线长度须 ≤0.20。曲率还要求变体极差除以 max(0.25，主中线曲率) ≤0.60。
- 夹角还要求可用着生高度、通过筛查的变体近端方向与主方向偏差 ≤20°，以及 8%、12%、20% 近端窗口的方向互差 ≤15°。
- 每项主特征提供独立状态列。质量失败时主字段留空，保留可算的诊断值、所用参数、门槛与原因。质量规则衡量观测支持及邻域扰动表现，解剖叶基准确度仍待标注验证。

## 聚类与分组复算

将通过各自规则且六项特征完整的叶片纳入 StandardScaler 和欧氏 K-means，固定 K=3、k-means++ 初始化、50 次起点、随机种子 20261120，使用 Lloyd 迭代。簇 ID 依据原单位簇中心的着生高度比升序分配。聚类质量在六维标准空间中计算轮廓系数、Calinski–Harabasz、Davies–Bouldin 和簇内平方和。PCA 的前两轴及前三轴分别用于二维和三维图。方法细节见 [scikit-learn KMeans 文档](https://scikit-learn.org/stable/modules/generated/sklearn.cluster.KMeans.html)。

按植株逐株留出，缩放器与 K-means 每折仅使用其余植株的完整叶。比较共同训练叶的调整兰德指数（ARI），用训练叶的列联表最大匹配映射簇 ID。对留出叶与整批参照模型的标签计算一致率，有两片或更多可比叶时另计 ARI。批次参照本身含留出株，这一设计度量组内复算敏感程度。逐株折以及叶片加权和等株权重的总体一致率均保留。没有完整叶片的植株保留无法评估状态。单株测试输出特征与几何。 [ARI 定义](https://scikit-learn.org/stable/modules/generated/sklearn.metrics.adjusted_rand_score.html)

全叶和逐株表提供有效样本数及描述统计。植株是独立观测单位，叶片是植株内观测。簇编号只反映算法结果，空间排列和生物意义需要独立批次核验。

## 逐株熵形态聚类

每株单独对全部叶片执行加权 StandardScaler + K-means（K=3）。正式拟合中线的特征和整批六特征分簇仍保存在原表。新方法用同一种观测剖面为所有参与叶片计算 Shannon 熵，包括此前缺少正式中线熵的叶片。

### 观测剖面和输入特征

取最近叶点 p 作为起点，r 为该叶有效原始点。用本株茎点 Z 坐标的 99% 与 1% 分位数之差 H 归一化相对坐标 (r−p)/H。采用点云输入的 +Z 竖直约定。在 p 到原始叶点的三维距离的 0 至 99% 分位数之间划分 16 个等宽径向区间，保留含至少三个点的区间。将各区间 XYZ 的坐标中位数按区间顺序连接，并在开头加入原始最近叶点。至少需要三个有观测支持的区间。

| 特征 | 定义 | 平方距离权重 |
|---|---|---:|
| 观测方向 Shannon 熵 | 将剖面相邻非零线段与 +Z 的夹角按 10° 分箱。令 pⱼ 为第 j 箱线段长度占剖面总长的比例，熵为 −Σⱼpⱼlog₂pⱼ，单位 bit | 55% |
| 水平伸展 | 原始叶点相对 p 的水平距离的 95% 分位数除以 H | 15% |
| 末端落差 | 剖面最高点到最远径向区间中心的 Z 落差除以 H | 15% |
| 下行段占比 | 与 +Z 夹角至少为 100° 的线段长度占剖面总长的比例 | 15% |

各特征在本株内用 StandardScaler 标准化，再乘以对应权重的平方根。因此 55% 是聚类度量中的熵维设计权重，具体叶对的实际距离贡献随特征差异变化。配置沿用固定种子 20261120 和 50 次初始化。

### 三型名称与解释

- C3 耷拉型为标准化末端落差和下行段占比的簇中心之和最大的一簇。落差能体现叶片末段转向下，即便叶尖仍在叶基上方。
- 在其余两簇中，水平伸展簇中心较小的一簇称为 C1 聚拢型，较大的一簇称为 C2 伸展型。聚拢描述单叶相对紧凑的观测形态。

三个标签表示本株内相对形态。各株均强制拟合三个簇，因此类型解释需要结合数学定义、簇中心和着色点云核验。观测剖面按离叶基的径向距离排列，可能把回折或遮挡叶片的不同部位并入同一区间。输入不足、缺少任一特征或无法形成三个可区分向量时保留失败状态。单叶簇保留，恰好三片叶各自成簇时轮廓系数未定义。
