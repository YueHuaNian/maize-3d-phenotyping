# PAI 株型指数与 LMI 叶形指数

`pai-lmi-baseline-v1` 是项目内的描述性基线。PAI（Plant Architecture Index）逐株计算，LMI（Leaf Morphology Index）逐叶计算。两者采用固定换算和等权设计，各分量越大表示对应几何特征越明显。分值在 0–100 尺度上，权重暂无外部标定。聚类与 V2 分层可用于查看点云，指数计算独立于类别标签和强制中层多数规则。

## 输入与归一化

沿用 V1.0 最近点对和 V1.1 [原始叶点观测剖面](V1.1_METHODS.md#观测剖面和输入特征)。本株有效茎点的 Z 坐标 99% 与 1% 分位数之差记为 H。叶基相对高度 h = (z − Q01) / H，z 取最近茎点的 Z 坐标。h 使用原始比值，允许落在 [0, 1] 之外。剖面特征采用同一 H 作尺度。非负比值 x 通过 f(x) = x / (1 + x) 压缩至 [0, 1)，x = 1 时分量为 0.5。分位数使用 NumPy 的线性插值。

## LMI（逐叶）

| 分量 | 定义 |
|---|---|
| 方向熵 E | 观测方向 Shannon 熵（bit）除以 log₂(18)，18 为固定倾角箱数 |
| 伸展 R | f(r)，r 为有效叶点相对叶基最近叶点的水平距离第 95 分位数除以 H |
| 下垂 D | [f(d) + p] / 2，d 为剖面最高点到最远区间中心的 Z 落差除以 H，p 为下行段长度占比 |

LMI = 100 × (E + R + D) / 3。至少需要三个有数据支撑的剖面区间和全部四项原始特征。缺失时分数留空，逐叶表保留已获得的分量、质量状态及缺失字段。逐株 LMI 中位数基于本株有效叶，并记录有效叶数、覆盖率及完整或部分覆盖状态。

## PAI（逐株）

| 分量 | 定义 |
|---|---|
| 横向伸展 Rₚ | 本株各叶 R 的中位数 |
| 着生高度跨度 Vₚ | f(Q90(h) − Q10(h))，对本株逐叶相对高度 h 计算分位数 |

PAI = 100 × (Rₚ + Vₚ) / 2。要求至少三片已识别叶、H 大于零，并且这些叶都有配对取得的高度和有效水平伸展。若不满足，保留已有分量与覆盖数量，PAI 留空。该定义描述叶片横向伸展及着生高度分布，未纳入叶面积、产量或田间适应性。

## 适用范围与复现

- 从原始配对点云运行 [分析入口](../run_analysis.py)，详见 [README 的复现步骤](../README.md#从原始点云复现)。运行目录的 `indices/` 下有逐叶 CSV、逐株 CSV、样本报告和溯源 JSON。溯源记录原始点云文件哈希、输入表哈希、运行参数和依赖版本。核对输入表和代码哈希时，统一使用 LF 换行。工作区含修改时，以记录的源码哈希核对实际运行版本。
- 植株是独立观测单位。批次 LMI 中位数按叶片汇总。比较植株时应同时读取逐株 LMI 中位数与覆盖率。
- 最近点对、输入 Z 轴方向、点云遮挡和剖面分段都会影响分值。当前权重定义用于描述观测几何，跨批次可比性和生物学关联需结合独立数据检验。关于玉米点云中叶片几何特征的测量，可参见 [Thapa 等的三维表型研究](https://doi.org/10.3390/s18041187)。
