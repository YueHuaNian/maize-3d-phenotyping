# 全局欧氏最近邻叶基定位

设 Pᵢ 是当前植株中标签为 i 的所有有效叶点，Pₛ 是同株标签为 0 的所有有效茎点。对每个实际出现的正整数 i，求解

(pᵢ*, qᵢ*) = arg min ‖p−q‖₂，p ∈ Pᵢ，q ∈ Pₛ。

最近距离 dᵢ = ‖pᵢ*−qᵢ*‖₂。

## 输入核验

按文件名配对 TXT 与语义 CSV，检查 TXT 声明点数和两文件的实际点数，再逐行检查解析后的 XYZ 和语义标签。对应位置的 NaN 视为相同的缺失坐标，含非有限 XYZ 的点不进入计算。涉及点数、坐标或标签的不一致时，终止该株计算并记录输入错误。输入文件的原始字节用于 SHA-256。

## 查询与并列处理

1. 按源行序构建茎点 cKDTree。
2. 找到当株所有正整数叶号，保持原标签。
3. 用 p=2、eps=0 对该叶所有有效点查询一个最邻近的茎点距离；在全部查询距离中取最小值。
4. 浮点查询距离严格相同时，优先选择源行号最小的叶点。对已经选定的叶点逐次增加 k，取同一最小距离中源行号最小的茎点。比较按查询返回的浮点值，零距离参与选择。
5. 输出两点的源坐标和零基点数据行号，计数保留实际原标签点数及有效点数。

每株建树一次。查询覆盖该叶的所有有效点，不设空间半径，也不使用几何方向、曲率或预筛选。两种原始文件的点数据索引一致。输出行号加 2 即 CSV 实际文本行号，加 3 即 TXT 实际文本行号，文本行号从 1 开始。

## 失败状态

| 状态 | 含义 |
|---|---|
| ok | 获得有效最短点对 |
| input_failed | 文件缺失、不可读、格式错误或对齐失败。该记录的 leaf_id 为空 |
| no_leaf_points | 核验通过的植株没有正标签。该记录的 leaf_id 为空 |
| no_valid_leaf_points | 有对应叶号，叶片 XYZ 全部无效 |
| no_valid_stem_points | 植株没有有效茎点 |
| distance_out_of_range | 最短距离超出查询可表示范围 |

结果是基于输入采样和标签的初始叶基估计。几何距离的 IQR 异常仅描述该批次分布。V1.0 报告将独立植株作为统计样本单位，叶片距离仅用于描述。
