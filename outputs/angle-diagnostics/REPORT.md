# 叶茎夹角缺失诊断

共 90 片叶，33 片有效，57 片缺失。状态为程序首个阻断阶段，不能理解为唯一原因。

| 状态 | 解释 | 叶片数 |
|---|---|---:|
| ok | 有效 | 33 |
| ANCHOR_CURVE_GAP | 叶基与中线起点距离过大 | 20 |
| LEAF_STEM_GAP_LARGE | 最近茎叶点距离超过门槛 | 8 |
| PROXIMAL_DIRECTION_UNSTABLE | 叶基方向不稳定 | 8 |
| LEAF_COMPONENT_FRAGMENTED|ANCHOR_CURVE_GAP | 点云断连且叶基与中线起点距离过大 | 6 |
| STEM_PROJECTION_AT_BOUNDARY | 茎线投影落在边界 | 5 |
| LEAF_COMPONENT_FRAGMENTED | 叶点主连通分量不足 | 3 |
| STEM_PROJECTION_UNSUPPORTED | 茎线投影缺少支持 | 3 |
| LEAF_POINTS_TOO_FEW | 叶点少于 200 | 2 |
| MIDLINE_VARIANTS_UNSTABLE | 中线拟合扰动不稳定 | 2 |

叶基与中线起点距离过大的叶片共 26 片（含组合状态）。距离除以门槛的中位数为 2.01，范围 1.01–13.90。
其中 9 片另有茎线投影边界或支持问题，3 片的茎叶距离也超门槛，8 片的近端窗口方向变化超过 15°；这些数量相互重叠。

状态按程序顺序产生；早期失败后，后续扰动稳定性可能未执行，空白表示未计算而非通过。
诊断角度只是中间计算值，未通过质量筛查，不能替代正式夹角。
结果不能单独区分遮挡、分割问题、叶基误定位或中线方法偏差；需查看原始点云及人工标注。

## 建议的排查顺序

1. 对叶基到中线起点距离超限的叶片，叠加点云、叶基点和中线，人工核验叶基与近端拟合。
2. 对茎叶距离超限和茎线边界问题，核验语义分割、茎线覆盖和最近点对位置。
3. 对方向或拟合不稳定的叶片，比较不同窗口和邻域参数的局部方向及点云支持。
4. 在人工标注样本上对比改进方法，记录误差和覆盖率后，再考虑更改正式质量规则。
