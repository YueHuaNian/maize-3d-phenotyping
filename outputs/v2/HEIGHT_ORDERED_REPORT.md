# V2 高度优先的逐株三分类

14/14 株得到三个连续高度组，90/90 片叶获得标签。

按最近茎点的 Z 高度排序，各株分别标准化。以加权簇内平方和最小为目标，在不同高度之间选择两个切点。叶基高度权重 65%，观测方向 Shannon 熵 20%，水平伸展、末端落差和下行段占比各 5%。

上层为 C1 聚拢型，中层为 C2 伸展型，下层为 C3 耷拉型。高度分层依据叶基，叶尖仍可跨越分层边界。
